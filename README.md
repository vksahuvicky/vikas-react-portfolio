# Vikas Kumar — React Portfolio

A responsive React/Vite portfolio for a Senior Front-End / React Developer.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Before publishing

Edit `src/main.jsx` and replace:
- `YOUR_EMAIL@example.com`
- `+91 XXXXX XXXXX`
- LinkedIn placeholder
- Project descriptions/titles with your actual projects
- Experience company/title details if required

GitHub is already set to:
`https://github.com/vksahuvicky`

## Free deployment

Push this folder to GitHub and import the repository into Vercel. The Vercel deployment can use the default free `vercel.app` domain.
